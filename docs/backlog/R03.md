## Implementation checklist (10 items)

- [ ] **R03.01 — HTTP and contracts**
  - Implementation: Implement Bun.serve versioned REST, schema validation, request IDs, RFC9457 errors, auth/scoping middleware, idempotent mutations and expected versions. Expand OpenAPI slice by slice; health/version no tenant details.
  - Acceptance: Contract tests for valid, invalid, 401/403/404/409/422/429 responses; no direct storage bypass; loopback authenticated.

- [ ] **R03.02 — Enrollment tokens**
  - Implementation: Operator creates expiring one-use scoped invitation; join atomically exchanges token for revocable agent credential; hash tokens, rotate and expire, verify immutable colony ID and protocol. Require TLS remote.
  - Acceptance: Replay, expired, wrong-scope, wrong-host and revoked tokens rejected; no credentials in URLs/logs.

- [ ] **R03.03 — CLI local and remote join**
  - Implementation: Implement join --url --profile --token-stdin, context/status via HTTP, timeout/error mapping, same contract for localhost/remote. Client composition root imports contracts/transport only.
  - Acceptance: Clean client joins existing host without DB/listener; remote TLS failure fails closed; JSON stable.

- [ ] **R03.04 — Connection profiles**
  - Implementation: Persist named endpoint/colony/principal/protocol plus keychain/protected credential ref, explicit active profile and override. No silent fallback or lease reuse; permissions restrictive.
  - Acceptance: Two profiles isolated; wrong colony and ambiguous mutation rejected; offline no silent local init.

- [ ] **R03.05 — Agent Registry**
  - Implementation: Durable AgentIdentity, status, capabilities, scoped enrollment and revocation; distinct provider/model metadata (not authorization). Operator reads/updates registry; last seen not assumed online.
  - Acceptance: Revoked identity denied across routes; other colony cannot enumerate or mutate; no fake online count.

- [ ] **R03.06 — Roles and sessions**
  - Implementation: Versioned Planner/Worker/Reviewer role profile and assignment separate from identity/model/session/runner; open/heartbeat/end session, TTL and scope recheck; independent principal requirement. Scout etc later.
  - Acceptance: Role spoof, expired session and self-review rejected; replacing session cannot inherit predecessor authority.

- [ ] **R03.07 — Typed Blackboard**
  - Implementation: Implement threaded typed posts (observation/hypothesis/proposal/discovery/blocked/negative_result/checkpoint/result/review/decision/handoff), scoped links, pagination, provenance, sanitization. System events separate from untrusted text.
  - Acceptance: Two agents exchange posts; negative findings retained; arbitrary user post cannot forge system transition or grant authority.

- [ ] **R03.08 — Event Store and Outbox**
  - Implementation: Atomic state+event+outbox writes, transactional per-colony sequence decimal string, correlation/causation, dedup consumer receipts, retries; projections rebuildable. Schema version registry.
  - Acceptance: Crash between state/event rolls back; replay duplicate produces one effective projection; cross-colony sequence isolation.

- [ ] **R03.09 — SSE and event recovery**
  - Implementation: Authenticated stream scoped per connection and replay, Last-Event-ID/cursor, bounded buffer, heartbeat, revoke disconnect, gap/retention snapshot recovery. No raw secrets.
  - Acceptance: Reconnect after disconnect obtains ordered events; missing cursor resync; no cross-tenant leak or revoked stream.

- [ ] **R03.10 — Search and Context Packet**
  - Implementation: SQLite FTS5 + bounded fallback, filter authorization before retrieval; packet version, constitution/hash, goal/revisions, role, criteria, plans/intents, work, checkpoint, verified/disputed/negative knowledge, blockers/approvals, cursor/asOf/truncation. R04 fills missing sections.
  - Acceptance: Fresh agent recovers relevant evidence, source refs and failed approaches within caps; stale/unverified marked; no cross-scope results.

## Milestone exit gate
Two independent clients on separate machines or isolated processes join same served colony without local DB/listener; replay, scoped auth and bounded context demonstrated.
