## Implementation checklist (8 items)

- [ ] **R01.01 — Initialize TypeScript monorepo**
  - Implementation: Create apps/ants and minimal contracts/domain/application/cli/storage-sqlite/config packages, strict TS, explicit exports; domain cannot import Bun/DB. Preserve MIT and docs. Defer unused packages.
  - Acceptance: Fresh checkout typechecks and runs CLI; dependency-boundary test rejects domain→storage import.

- [ ] **R01.02 — Workspace and lockfile**
  - Implementation: Spike Bun Workspaces vs pnpm/Turborepo; choose one via O02 ADR, pin tool/runtime versions, one lockfile, scripts install/build/test/typecheck/lint and frozen CI install.
  - Acceptance: Two clean installs resolve same lockfile; lockfile drift fails CI.

- [ ] **R01.03 — Minimal CLI help/version**
  - Implementation: Entry point with help/version, --json, noninteractive parsing; separate host/client/runner composition roots. JSON stdout, diagnostics stderr, documented exit classes; version build metadata.
  - Acceptance: Subprocess tests assert stdout/stderr and exit codes; invalid command fails without creating DB/listener.

- [ ] **R01.04 — Standalone compilation**
  - Implementation: Use Bun --compile, build artifact outside source tree; record architecture, size, SHA256, command. Test Linux clean host without runtime; probe other OS targets and embedding sample static assets (O01/O04), no unsupported claims.
  - Acceptance: Binary works on clean Linux; actual matrix and limitations recorded; no mandatory Node/Bun install.

- [ ] **R01.05 — SQLite and FTS5**
  - Implementation: bun:sqlite adapter, foreign_keys, WAL, busy timeout, prepared queries, rollback, local data dir; test FTS5 and bounded lexical fallback. Decide migration tooling/time/IDs via O05.
  - Acceptance: Persist/reopen/search fixture from binary; absent FTS fallback, failed transaction and contention tested.

- [ ] **R01.06 — Migration foundation**
  - Implementation: Versioned ordered migrations with applied checksum/history, serialized migration writer, transactional changes where supported, backup/upgrade guidance; minimal scoped fixture schema, not all future tables.
  - Acceptance: Fresh install, repeat no-op, upgrade and injected failure rollback; changed applied checksum rejected.

- [ ] **R01.07 — Testing and lint**
  - Implementation: Choose Bun Test or Vitest, pure domain unit tests, real SQLite temp DB integration, CLI subprocess tests, lint/format and strict typecheck. Deterministic fixtures, no provider keys.
  - Acceptance: Root check passes; intentionally failing fixture returns nonzero; no state/secrets tracked.

- [ ] **R01.08 — GitHub Actions CI**
  - Implementation: PR/push workflow, least privileges, pinned tools, frozen install, lint/typecheck/test/build, clean-host smoke and artifact checksum; no automatic release yet.
  - Acceptance: Actual successful workflow linked to SHA, failing test blocks check, artifacts hash-verifiable.

## Milestone exit gate
Clean Linux machine runs compiled CLI and SQLite fixture without installed Bun/Node; actual CI and binary compatibility report, ADRs for tooling; no external services.
