## Implementation checklist (7 items)

- [ ] **R02.01 — Organization and Colony**
  - Implementation: Implement scoped organization/colony schema, ownership, explicit local data-dir, composite FKs and application authorization; local single operator is not implicit trust. Add init/status/serve foundation and migrations.
  - Acceptance: Two scopes cannot read/write each other's records; restart preserves identity; init refuses existing unrelated state.

- [ ] **R02.02 — Constitution versioning**
  - Implementation: Import Markdown plus validated structured limits, immutable revision/hash, human-approved current pointer, audit old/new versions; effective scope cannot widen hard policy. Export readable copy, DB authoritative.
  - Acceptance: Agent update and stale expected version rejected; revision/hash survive restart; prior revisions readable.

- [ ] **R02.03 — Mission lifecycle**
  - Implementation: Draft/active/paused/completed/cancelled lifecycle container linked to approved constitution, scope and deadlines. Explicit operator transitions and state guards; terminal immutable; completion rules per 22.
  - Acceptance: Illegal transitions rejected; cancellation does not masquerade as completion; child operations honor parent state.

- [ ] **R02.04 — Goals and acceptance criteria**
  - Implementation: GoalRevision and Criterion records, objective, trusted verifier reference/rubric, required flag, evidence state, explicit resource envelope and deadline; draft/active/verifying/blocked/paused/exhausted/succeeded/cancelled/failed; one pursued slot per mission per 22. Goal Engine later.
  - Acceptance: Validate activation and slot race; reject missing criteria/limits and unauthorized changes; no success by task count.

- [ ] **R02.05 — Foundational policies**
  - Implementation: Versioned policy scope intersection, hard deny precedence, default deny unknown controlled effect, role/session scopes; expose deterministic decision service (approval consumption in R06). Persist budget/deadline policy and reject agent expansion.
  - Acceptance: Table tests allow/ask/deny, missing scope and child widening; no board text can confer authority.

- [ ] **R02.06 — Operator bootstrap**
  - Implementation: Design O06 first-owner setup with explicit local ownership, distinct human/agent principals, secret hashing/restrictive storage, loopback auth, no URL/argv credentials; secure session bootstrap and operator-only commands. Document enrollment follows R03.
  - Acceptance: Second bootstrap cannot seize ownership; unauthorized local requests fail; secrets absent from logs and DB plaintext.

- [ ] **R02.07 — Pause, resume, cancel**
  - Implementation: Persist scope-specific stops with revision/version checks; deny new work, invalidate affected authority and pending grants, audit; explicit human resume, terminal cancellation irreversible. Define hooks for leases/dispatch R04/R06.
  - Acceptance: Pause survives restart; stale authority rejected, operator resume fresh authority; cancelled goal cannot auto-resume.

## Milestone exit gate
Operator boots local host, creates constitution/mission/goal, restarts and observes preserved criteria and limits; unauthorized/stale lifecycle commands fail.
